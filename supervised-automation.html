Supervised automation: the agent prepares work; nothing takes effect until a user approves it. This is the core pattern from the JD — "build supervised automations where outputs are reviewed and approved by users before implementation."

1 · Document check agent

Run the agent against a sample source document. The agent extracts structured fields, validates them against GxP-style rules, and files the result in the approval queue — it never writes to the system of record.

2 · Approval queue supervised

Each item below is agent-prepared. Approve to implement it to the system of record (with an e-signature audit entry), or reject to send it back with a reason.

3 · Audit trail immutable, 21 CFR Part 11 style

Every action — agent runs, approvals, rejections — is written to a tamper-evident log with user, timestamp, and reason. This is what makes AI output acceptable in a regulated environment.
